# Lumière Fine Jewellery 💎
### A Full-Stack E-Commerce Platform with AI-Powered Admin Intelligence

A production-grade jewellery e-commerce web application built with 
Node.js, Express.js, SQLite, and vanilla HTML/CSS/JS — featuring a 
luxury storefront and a comprehensive admin panel with AI inventory insights.

## Features
### Customer Storefront
- Luxury UI with product browsing by category (Bracelets, Rings, 
  Bangles, Necklaces, Anklets)
- Shopping cart, checkout with multiple payment methods 
  (EasyPaisa, JazzCash, Cash on Delivery, Bank Transfer)
- JWT-based authentication with separate customer and admin roles
- Wishlist, order tracking, and account management
- Newsletter subscription and Journal/Blog section

### Admin Panel
- Real-time dashboard with revenue, orders, products, 
  and customer metrics
- Full product management — add, edit, hide, image upload + URL support
- Order management with status updates
- Customer management with spend tracking
- **AI Inventory Control** — stock health monitoring, price alerts, 
  top-selling products, category sales analytics, 6-month revenue trends
- **SEO & SEM Panel** — Core Web Vitals monitoring, keyword tracking, 
  competitor analysis, backlink management, robots.txt & sitemap checks

## Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend:** Node.js, Express.js
- **Database:** SQLite with normalized schema
- **Auth:** JWT (JSON Web Tokens)
- **Architecture:** MVC pattern, RESTful API

- LCP: 0.17s ✅

## Getting Started
```bash
git clone https://github.com/Raheeba15/lumiere-jewellery
cd lumiere-jewellery
npm install
node server.js
```
Visit `http://localhost:3000`

Admin access: `/admin`
