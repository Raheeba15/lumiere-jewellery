# Lumière Fine Jewellery 💎

A full-stack e-commerce web application for a fine jewellery store, 
built with Node.js, Express.js, SQLite, and vanilla HTML/CSS/JS.

## Features
- Product browsing with category filters
- Shopping cart and checkout flow
- JWT-based authentication
- Separate customer and admin dashboards
- Admin can manage products, orders, and users

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** SQLite
- **Auth:** JWT (JSON Web Tokens)

## Getting Started
```bash
git clone https://github.com/Raheeba15/lumiere-jewellery
cd lumiere-jewellery
npm install
node server.js
```
